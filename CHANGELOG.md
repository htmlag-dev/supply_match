# Изменения 18.10.2026

- Новый адаптивный интерфейс: обзор, поиск, база, сравнение, история, стоимость покупки, заказы, тарифы, внешний вид и AI-настройки.
- Поиск по странам, категориям, количеству, бюджету, состоянию и цели покупки; четыре готовых изменяемых сценария.
- Реально установлена Qwen3-4B Q4_K_M и официальный runtime llama.cpp; добавлены автозагрузка, автозапуск и индикация состояния.
- Добавлен бесплатный OpenRouter fallback, Groq, Anthropic, пользовательский совместимый API; Gemini сохранён.
- Подключён API веб-поиска Tavily с источниками. Без источников цены, контакты и коммерческие условия от ИИ удаляются.
- Карточки расширены страной, категорией, форматом сделки, валютой, ценой, MOQ, сроками и Incoterms. Старые базы мигрируют с сохранением записей.
- Добавлены ручное создание и редактирование, фильтрация, CSV с защитой от формул, письма с копированием.
- Добавлен калькулятор стоимости партии и единицы с доставкой, валютой и сценарием перепродажи.
- Реализованы пробный период 14 дней, бесплатный Старт и Профи; серверные лимиты и история.
- Разделены подписка и заказы товаров. Адаптер ЮKassa создаёт redirect-платежи при настройке реквизитов и проверяет статус у провайдера. Повторные запросы и уведомления обрабатываются без повторного списания/продления.
- Добавлены светлая, тёмная и системная темы, четыре цвета, плотность, имя пространства и стартовый экран.
- Подготовлены PWA, проекты Android/iOS, собственные иконки и native открытие платежной страницы товара.
- Исправлено закрытие SQLite-соединений, добавлены проверки JSON, безопасный вывод текста, токен пространства и CORS для мобильных клиентов.
- Обновлены инструкции запуска, оплаты, AI и мобильных сборок; старый HTML стал страницей запуска актуального приложения.

Реальные платежи не выполнялись. Мобильные платформы подготовлены как исходные проекты, без подписанных APK/IPA и публикации в магазинах. Работа с сетью проверена через локальную модель; внешний AI/поисковый и платёжный API проверен тестовыми ответами, поскольку ключи не предоставлены.


## Аккаунты, оформление и корзина

- Обязательная авторизация, владелец alexapp, обычные роли для новых пользователей, отзывные 30-дневные сессии.
- Шифрование личных баз AES-256-GCM, хеширование паролей scrypt, защита сессий и CSRF, серверные роли и админ-панель.
- Подтверждение почты одноразовым кодом через SMTP/TLS; без SMTP нет имитации отправки. Серверные OAuth-потоки Google/Apple требуют ключей владельца.
- Деньги в админ-панели отображаются с двумя десятичными знаками.
- Веб-поиск без ключа через DDGS, несколько запросов, фильтры и следующие страницы; исправлена галочка для встроенной модели.
- Готовые и пользовательские темы, сохранённые режимы, проверка контраста, WebGL-свечение и настройки движения.
- Каталог моделей по категориям, CSV и поиск страниц, неизвестные значения без выдуманных цен и остатков.
- Корзина разных моделей и поставщиков, расчёт расходов и сроков, сравнение идентичных комплектаций и отдельные заказы поставщикам.

## Оптимизация 19.10.2026

- Чтение настроек один раз на запрос с изоляцией потоков, ограниченный кеш объектов личных хранилищ.
- Обновление активности сессии раз в пять минут без изменения срока 30 дней.
- Загрузка каталога выбранного поставщика по индексу, компактные ответы корзины.
- Удалённые модели остаются удаляемыми из корзины, некорректные идентификаторы отклоняются без внутренней ошибки.
- 43 серверных теста; замеры и ограничения — docs/AUDIT_AND_OPTIMIZATION.md.
