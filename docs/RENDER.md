# Бесплатное размещение: Render + Supabase

Проект содержит `render.yaml` с одним Web Service на тарифе `free`. Платная база Render и постоянный диск не создаются. Supabase подключается отдельно. Это бесплатные тарифы в пределах лимитов, а не гарантия неизменных условий навсегда.

## Первое размещение

1. Войдите в Supabase, создайте отдельный проект в организации Free. Пароль базы задайте и сохраните самостоятельно.
2. В Connect выберите **Session pooler**, порт **5432** (совместим с IPv4). Скопируйте PostgreSQL URI, подставьте пароль с URL-кодированием специальных символов и добавьте `?sslmode=require` (или `&sslmode=require`, если параметры уже есть). Это секрет: не публикуйте его в GitHub, чате или скриншотах.
3. В Render выберите **New → Blueprint**, подключите репозиторий `htmlag-dev/supply_match`, ветку `main`. Проверьте, что единственный сервис использует **Free**.
4. Укажите секреты в форме Render:
   - `SUPPLY_MATCH_DATABASE_URL`: URI из Supabase.
   - `SUPPLY_MATCH_BOOTSTRAP_EMAIL`: ваш email для входа в приложение.
   - `SUPPLY_MATCH_BOOTSTRAP_PASSWORD`: новый уникальный пароль приложения (12–128 символов). Не пароль GitHub/Render.
5. Render автоматически создаст постоянный ключ `SUPPLY_MATCH_ENCRYPTION_KEY`. Сохраните его в менеджере паролей. Не меняйте при перезапуске и не выкладывайте в репозиторий.
6. После успешной сборки откройте выданный Render HTTPS-адрес и войдите с указанными данными. Первый администратор создаётся один раз, повторный запуск не меняет его пароль.
7. После первого успешного входа удалите обе переменные `SUPPLY_MATCH_BOOTSTRAP_*` из Environment Render. Ключ шифрования и URI базы оставьте.

Запуск: `python scripts/start_render.py`. Он устанавливает production, использует PORT Render, разрешает HTTPS-домен сервиса и не запускает локальную AI-модель. HTTP слушает 0.0.0.0 только в явно распознанном окружении Render за его TLS-прокси. Обычный production-запуск по-прежнему требует localhost.

## Что проверить после размещения

- Сайт открывается по HTTPS, вход работает, cookie сессии имеет Secure.
- Добавленная тестовая запись остаётся после перезапуска сервиса.
- Неавторизованные запросы к личным API отклоняются.
- В логах нет паролей, ключей или URI базы.

На облаке создаётся новая база. Локальные данные и аккаунты не переносятся автоматически. Для их переноса предусмотрен `scripts/migrate_postgres.py`; перенос требует отдельной проверки и резервной копии. Схемы sm_* не следует добавлять в exposed schemas Supabase Data API.

## Ограничения Free

- Render засыпает после 15 минут простоя, пробуждение занимает около минуты. Перед презентацией откройте ссылку заранее.
- Supabase может приостановить проект после недели неактивности; восстановление доступно в панели в пределах условий провайдера.
- Render Free блокирует стандартные SMTP-порты. Вход созданного владельца работает без почты; регистрация и вход по умолчанию работают без подтверждения почты. Сброс пароля через email требует отдельной настройки совместимой доставки писем. Обязательное подтверждение можно вернуть переменной SUPPLY_MATCH_REQUIRE_EMAIL_VERIFICATION=true.
- AI требует внешнего провайдера, его доступности и лимитов. Локальная Windows-модель на Render не запускается.
- Мониторинг не работает, пока веб-сервис спит. Онлайн-платежи/OAuth требуют собственных настроек.
- Не выбирайте платные ресурсы для этой демонстрации. При достижении бесплатных лимитов возможна приостановка.
