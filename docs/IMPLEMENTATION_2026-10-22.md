# Проверка изменений — 22 октября 2026

Реализованы отдельное сравнение стоимости точной модели, даты проверки условий, этапы заказа и история доставки, предпросмотр и обновление прайсов CSV/XLSX, личные закупочные проекты, сохранённые поиски и ежедневный opt-in мониторинг, уведомления внутри приложения, почтовое восстановление пароля, зашифрованные SQLite-копии и опциональный PostgreSQL с переносом данных.

## Выполненные проверки

- Общий Python-набор: 60 тестов, 58 успешных, 2 PostgreSQL-теста пропускаются без настроенного сервера.
- На отдельном временном PostgreSQL: 18 успешных проверок. Включены корзина, расчёт, импорт, изоляция, восстановление пароля, CSRF, конкурентный лимит и миграция SQLite с откатом/сохранением. Ни личные базы, ни рабочий сервер не переключались на PostgreSQL.
- JavaScript: синтаксис всех web-скриптов; 3 успешных проверки контраста.
- В браузере на отдельной временной базе: вход, создание проекта, связь с поставщиком, сравнение с явным указанием неизвестных расходов, сохранение поискового запроса и его появление на странице мониторинга. В проверенных сценариях ошибок JavaScript нет. Снимок: [страница мониторинга](screenshots/procurement-monitoring.png).
- Создание, проверка целостности, восстановление SQLite-копии; неверный ключ и изменённый архив отклоняются. Восстановленные сессии отзываются.
- Подготовка web-ресурсов Capacitor и синхронизация Android/iOS прошли.

## Практические ограничения

- Локальная сборка Android была запущена и остановилась из-за отсутствия Android SDK. Java 21 и Gradle работают. На Mac отсутствует полноценный Xcode, сборка iOS локально не выполнена.
- В GitHub Actions добавлены задания Android debug APK и iOS Simulator. Их добавление не означает успешного прохождения: результаты смотрите во вкладке Actions. На реальных устройствах приложение не проверялось, подпись и публикация не выполнялись.
- Реальные SMTP, платёжные реквизиты и OAuth требуют конфигурации владельца. Отправка писем и платежи в тестах заменены заглушками. Боевых писем и списаний не выполнялось.
- Мониторинг сообщает о новых ссылках; цены произвольных сайтов автоматически не извлекаются. Уведомления изменения цены возникают при обновлении личного каталога.
- PostgreSQL — опциональный backend. Подключение к production, TLS/дисковое шифрование, KMS, плановые копии и нагрузочная проверка выполняются оператором по [инструкции](OPERATIONS.md). Текущие пользовательские данные остаются в исходном SQLite-хранилище.
