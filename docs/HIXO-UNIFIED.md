# Автономная презентация Supply Match

Исходники в `hixo/`. Собрать: `python3 scripts/build_unified_hixo.py`.
Архив `build/Supply-Match-Unified-Hixo.zip` загружается в существующий проект Hixo вместо прежней серверной версии. В корне архива index.html. Для посетителей Python не нужен; Render и Supabase не используются.

Новый интерфейс объединяет каталог, фильтры, избранное, сравнение до четырёх компаний, шаблон запроса КП, корзину с ручными ценами и доставкой, проекты с бюджетами, журнал заказов, экспорт/восстановление локальных данных. Неизвестные цены блокируют сохранение заказа. Данные хранятся в браузере; перенос между компьютерами через резервную копию.

Нейроподбор — небольшая двухслойная сеть 128→16→категории, обучаемая в браузере на 45 записях встроенного справочника. Это экспериментальная классификация, а не универсальный языковой помощник. Подсказка категории применяется пользователем. Качество на независимой выборке не оценено. Поиск новых компаний открывает внешний поисковик.

Справочник взят из предоставленного прототипа; актуальность компаний и условий не подтверждена. Приложение не отправляет заявки, не получает реальные предложения, не проводит оплату. Статусы вводит пользователь. Аккаунты, общая база и серверный поиск остаются возможностями отдельной Render-версии.

Проверено в браузере: запуск, карточка, добавление позиции, блокировка заказа с неизвестной ценой, сохранение цены 125 ₽ и заказа, поиск «упаковка» и применение нейроподсказки «Упаковка» (5 компаний). Интерфейс заново написан, HTML пользователя использован как источник идей и справочника.
