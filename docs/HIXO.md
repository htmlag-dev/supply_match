# Две версии: Render и Hixo

Обе версии используют один API на Render и общую PostgreSQL-базу. Аккаунты и данные сохраняются; вход на каждом домене отдельный. Hixo публикует интерфейс, а не Python-сервер. ZIP не автономен: при недоступности Render вход, поиск и сохранение не работают. Бесплатный Render по-прежнему засыпает после простоя. Мониторинг работает только пока сервер запущен.

## Режим без ИИ

`configure_render()` по умолчанию выставляет `SUPPLY_MATCH_NO_AI=1`. Поиск всегда обращается к поисковым системам через DDGS, даже если остались ключи Tavily или модели. Ключи не требуются. Страницы, заголовки и фрагменты выдачи не подтверждают цены, наличие и добросовестность продавца. Поиск ограничен 30 запросами в час на аккаунт; поисковые системы могут ограничить доступ со своей стороны.

Письмо — редактируемый шаблон, отправляется пользователем самостоятельно. Сводка сравнения показывает заполненность шести полей, а не оценку качества продавца. Точное сравнение моделей и полная стоимость продолжают вычисляться по введённым условиям. Каталоги, CSV/XLSX, корзина, заказы, проекты, история, темы и администрирование остаются в общем приложении. Поиск не расходует AI-квоту. Лимиты количества поставщиков сохраняются.

Оплата и восстановление пароля, как и раньше, требуют настроенного платёжного провайдера и почты. Они не становятся автоматически доступными благодаря публикации на Hixo. Для OAuth используется основной сайт Render; в статической версии предусмотрен вход по email/логину.

## Сборка

```sh
python scripts/build_hixo.py
```

Результат: `build/Supply-Match-Hixo.zip`, только публичные файлы из `app/web`. В архив не включаются пароли, настройки окружения, база или ключи. Загружать исходный репозиторий целиком на Hixo нельзя.

1. Загрузить ZIP на https://hixo.ru/ и получить адрес своего проекта.
2. На Render добавить точный HTTPS origin опубликованного сайта в `SUPPLY_MATCH_ALLOWED_ORIGINS` (список через запятую, без завершающего `/`). Не разрешать весь `*.hixo.dev` или `*`.
3. Применить настройки и развернуть последний коммит на Render.
4. Проверить вход, создание поставщика, поиск и экспорт с опубликованного адреса.

Статическая версия хранит отзываемую сессию в `sessionStorage`, привязанную к фиксированному API origin сборки, и отправляет её в Authorization. Сторонние cookies не нужны; CSRF-проверка сохраняется. Закрытие вкладки очищает сессию. Основная версия Render продолжает использовать HttpOnly cookie. Для нативных клиентов сохраняется существующее защищённое хранилище.

Все формы (включая динамические) используют `data-hixo="off"`, чтобы Hixo не сохранял аккаунты, заявки и данные закупок как свои заявки. Документация: https://hixo.ru/guides/kak-hixo-rabotaet-s-formami .

Не выключайте Render: это сервер обеих версий. Для полностью независимого Hixo понадобится отдельный размещённый API; статический хостинг не выполняет серверный поиск.
