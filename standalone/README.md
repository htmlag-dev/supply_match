# Supply Match без сервера

Откройте `Supply-Match.html` двойным кликом в Safari, Chrome или другом современном браузере. Нужен только этот HTML; Python, Node.js, установка и интернет для локальных функций не нужны.

Работают поставщики, товары и сравнение цен, калькулятор расходов, проекты с бюджетом, ручной учёт заказов, светлая/тёмная тема, экспорт и восстановление JSON. Поиск открывает запрос в Google или Яндексе и требует интернета.

Это отдельная автономная версия. Аккаунтов, онлайн-оплаты, автоматического AI-поиска и мониторинга здесь нет. Данные серверной версии не импортируются автоматически.

Записи сохраняются в localStorage браузера, а не внутри HTML. Поддержка хранилища для локальных файлов зависит от браузера и его настроек; если оно недоступно, показывается предупреждение. При смене браузера, перемещении файла или очистке хранилища записи могут стать недоступны. Регулярно скачивайте резервную копию из раздела «Данные». JSON-копия не зашифрована.

Проверка: `node --test tests/standalone.test.cjs` из корня репозитория. Проверяет восстановление после перезапуска, расчёт, обработку повреждённой копии, экранирование и отсутствие внешних зависимостей. Визуальная проверка file:// встроенным браузером Codex недоступна из-за ограничения URL.
