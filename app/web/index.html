ПРОСТРАНСТВО ДЛЯ РОСТА

Подходящий план для ваших покупок.

От разовых покупок до регулярных закупок и перепродажи.

Пробная версия: 14 дней, 50 AI-действий, до 100 продавцов и история. После неё — бесплатный Старт. Профи расширяет лимиты. API провайдера и веб-поиск оплачиваются отдельно, если используются ваши ключи. Приём оплаты подписки готовится к подключению.

Просто и прозрачно

Нужен ли отдельный API-ключ?

Не обязательно: встроенная Qwen3 работает без ключа после установки модели на сервере приложения. Можно использовать служебный OpenRouter или подключить свой API. Расходы по собственным ключам оплачиваются провайдеру отдельно.

Что произойдёт при оформлении тарифа?

Сохранится заявка с выбранным планом и стоимостью. Списания и активации подписки не будет, пока платёжный сервис не подключён.

Где хранятся мои данные?

База поставщиков, настройки и заявки хранятся локально на компьютере, где запущено приложение. Данные из AI-запросов передаются выбранному AI-провайдеру.

Импорт прайса CSV / XLSX

До 500 строк. XLSX: первый лист без формул. Совпадающий sku обновляет существующую модель; без sku добавляется новая. Разделитель ; или запятая. Столбцы: name, category, sku, comparison_key, unit_price, currency, availability (available/out/unknown), stock_qty, moq, lead_min, lead_max, source_url, note. Неизвестные значения оставляйте пустыми.

Полный ассортимент и актуальные остатки доступны только из каталога или API поставщика. Найденные страницы могут не быть товарными карточками; цены и наличие из них автоматически не выдумываются.
